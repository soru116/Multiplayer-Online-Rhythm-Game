# 網路程式設計-多人連線節奏遊戲

> 多人即時反應遊戲｜Python 結合 UDP 廣播與 TCP 連線，多執行緒支援多人同步對戰

伺服器隨機出題 ←↑↓→，所有玩家同時搶按，**1 秒內答對得 1 分**，20 輪後比總分高低。

---

## ✨ 特色

-  **多人連線**：一台伺服器，多位玩家同時加入
-  **UDP 廣播出題**：低延遲同步每輪方向，並有 TCP 備援
-  **TCP 可靠傳輸**：連線註冊、玩家列表、分數、結算
-  **多執行緒**：每位玩家獨立執行緒處理，搭配 Lock 保護共用資料
-  **心跳機制**：每 5 秒 ping/pong 偵測連線狀態
-  **Tkinter 介面**：即時顯示方向、分數、準確率、反應時間與排行

##  技術

| 項目 | 使用技術 |
|------|----------|
| 語言 | Python 3（僅用標準函式庫） |
| 架構 | Client-Server |
| 網路 | TCP Socket、UDP Socket（廣播） |
| 並行 | threading、threading.Lock |
| 訊息格式 | JSON |
| 介面 | Tkinter |

##  連接埠

| 連接埠 | 協定 | 用途 |
|--------|------|------|
| 12345 | TCP | 連線管理、分數、通知 |
| 12346 | UDP | 伺服器接收玩家作答 |
| 12347 | UDP | 客戶端接收方向廣播 |

##  執行方式

```bash
# 1. 啟動伺服器
python networking_server.py

# 2. 啟動客戶端（可開多個）
python networking_client.py
```

3. 在客戶端輸入**伺服器 IP**與**玩家名稱**，按「連接遊戲」
4. 有玩家連線後自動倒數 3 秒開始

## 🎮 操作與規則

- **操作**：方向鍵 `← ↑ ↓ →` 或 `W A S D`，也可點擊畫面按鈕
- **每局**：20 輪，每輪約 2 秒
- **得分**：方向正確且反應時間 ≤ 1000 ms 得 1 分
- **每輪限答一次**，作答後按鈕暫時鎖定
- **結算**：顯示排名，30 秒後自動開始下一局

##  遊戲流程

```
玩家連線 (TCP) → 註冊並取得 ID → 倒數 3 秒
   → 伺服器廣播方向 (UDP + TCP 備援)
   → 玩家作答 (UDP) → 伺服器判定並回饋 (TCP)
   → 更新分數 → 重複 20 輪 → 公布排名 → 30 秒後下一局
```
